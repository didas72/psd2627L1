# Procedures


## Procedure ADD/MUL/OR

- Set VALUE (operand 1) in the switches
- Select OPER (button press)
- Show VALUE in display
- Load VALUE into R1
- Set VALUE (operand 2) in the switches
- Press "equals"
- Store ALU result in R2 and send it to RESULT to be displayed
- Load R2 value into R1 to use as operand 1
- Select OPER (button press)
- Don't change display
- Set VALUE (operand 2) in the switches
- Press "equals"
- Store ALU result in R2 and send it to RESULT to be displayed
